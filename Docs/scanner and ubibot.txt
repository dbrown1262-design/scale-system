ubibot monitor

We installed 5 UbiBot ws1a monitors in the following locations:

Processing
Drying/Storage
Grow Room 1
Grow Room 2
Mom Room

The units record Temperature, Humidity, Illumination (Lux) and Voltage (important because they run on alkaline batteries that need to be replaced periodically)

All data are uploaded via wifi to the UbiBot server and accessed with their smartphone app and a web based console.
Each unit is allocated 200MB of storage and can download 1GB per month

in 11 days, the processing unit uploaded 1.6MB, monthly download traffic was 643Kb,
