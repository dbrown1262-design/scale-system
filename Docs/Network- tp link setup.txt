Network Topology

Our network uses Spectrum fiber network to access the internet.  A Spectrum Modem converts fiber cable to ethernet, which connects to a TP Link router WAN port. The router has 4 ethernet ports which connect to switches and the TTLock network interface.  (The TTLock interface is connected to the main router beacuse it has to be in bluetooth range of the lock.)  

The network includes a NetGear WiFi access point.  Some internal devices connect to the network over WiFi, and employees are allowed access for portable devices because our metal building blocks cellular signals.
