# PreRoll Production — Standard Operating Procedure (SOP)

**Document Location:** `sop/Processing/PreRollProduction.md`
**Function:** Processing
**Process:** PreRoll Manufacturing
**Applies To:** Ground Flower Handling, Cone Filling, PreRoll Packing, Closing & Finishing


## 1. Purpose

To define the standardized procedure for producing uniform, compliant cannabis pre-rolls using the PreRoll machine system, ensuring consistent weights, proper cone packing, and repeatable quality control.

---

## 2. Responsibilities

- **Processing Technician:** Execute all steps in pre-roll production.
- **Processing Lead:** Verify batch weights, quality, and process compliance.
- **QA / Compliance:** Ensure sanitation and traceability requirements are met.


## 3. Required Equipment & Components

### Machine Components
- PreRoll machine
- Grate (cone bounce grate)
- Collectors
- Cone tray and holder
- Press
- 109mm closing tray
- Start tray

### Dispensing System Components
- Dispensing tray
- Top alignment tray
- 2 × corner stacking pins
- Collection guard

### Tools
- Digital scale
- Star tamper
- Sliding cone holder
- Pegs for finished pre-roll transfer


## 4. PreRoll Production Procedure

### 4.1 Assemble PreRoll Machine

1. Assemble the machine using the following parts:
   - Machine body
   - Grate (for bouncing cones)
   - Collectors
   - Cone tray and holder
   - Press
   - 109mm closing tray
   - Start tray
2. Verify all components are properly seated and aligned.

### 4.2 Cone Tray Loading

1. Fill the cone tray with **167 cones**.
2. Leave **two corner positions empty** to allow placement of stacking pins in the dispensing tray.
3. Inspect cones for damage or deformities before loading.

### 4.3 Assemble Dispensing Tray

Assemble the dispensing system using:
- Dispensing tray
- Top alignment tray
- 2 corner pins
- Collection guard

Verify:
- Proper alignment
- Stable stacking
- Free movement of dispensing components



### 4.4 Weighing & Loading Flower

1. Place dispensing tray on scale and **tare**.
2. Weigh **minimum 60g per load**.
3. Prepare **3 loads per batch** (minimum total: 180g per batch).
4. Set tray on machine and dispense material evenly into cones.



### 4.5 Packing Operation

1. Set machine speed/control to **18–21**.
2. Run machine for approximately **5 minutes per load**.
3. Increase run time if ground flower is fluffy or low density.
4. Visually verify uniform packing during operation.


### 4.6 Pressing, Closing & Finishing

1. After all **3 loads** are packed:
   - Remove cone tray
   - Place tray into press
2. Use sliding holder to position cones into closing tray.
3. Apply **star tamper**:
   - Press onto paper
   - Use star side to close top of pre-roll
4. Use pegs to push finished pre-rolls onto tray.
5. Inspect finished pre-rolls for:
   - Proper closure
   - Uniform fill
   - Structural integrity


## 5. Quality Control

- Verify cone count per batch
- Verify batch weight totals
- Inspect closure quality
- Remove defective pre-rolls
- Document rework or waste


## 6. Sanitation Requirements

- Sanitize machine surfaces before and after production
- Sanitize trays, tampers, and tools
- Wear gloves during processing
- Prevent cross-strain contamination
- Dispose of waste material per facility SOP



## 7. Compliance & Traceability

- Maintain batch integrity
- Prevent strain mixing
- Follow NYS OCM processing and handling requirements
- Maintain production logs and batch records



## 8. Safety

- Keep hands clear of moving machine parts
- Power down machine before adjustments
- Report mechanical issues immediately
