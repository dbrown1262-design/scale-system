# Material Flow SOP — Harvest to Extraction

## Section 1 — Purpose

To define the controlled flow of cannabis material from harvest through extraction under a batch-level inventory system with internal tracking.

## Section 2 — Scope

Applies to all harvested cannabis material through processing into hash and rosin.

## Section 3 — Process Flow

Harvest → Wet Weigh → Dry → Dry Weigh → Buck → Batch Package Creation → Machine Pre-Trim → Partial Processing → Bulk Storage → Manual Trim → Smalls Accumulation → Extraction Split → Processing

## Section 4 — Process Description

### 4.1 Harvest and Weigh

* Plants harvested and weighed
* Identity maintained

### 4.2 Drying

* Controlled environment
* Identity preserved

### 4.3 Bucking

* Flower removed from stems
* Placed into totes

### 4.4 Batch Package Creation

* One METRC package created per batch
* Represents total weight across totes

### 4.5 Tote Structure

Each tote:

* Assigned Tote ID
* Weighed and recorded
* Labeled with strain, harvest date and weight

Totes are sub-units of a single package.

### 4.6 Machine Pre-Trimming

* Totes processed individually
* Processing recorded

### 4.7 Partial Processing Control

* Processing may occur over multiple days
* Each event must record weights for trimmed flower, smalls and trim

### 4.8 Mass Balance

System must show at all times:

* Original weight
* Processed weight
* Remaining weight

### 4.9 Storage

* Totes remain grouped
* No independent handling

### 4.10 Manual Trimming

* Flower refined
* Smalls generated

### 4.11 Smalls Accumulation

* Maintained within batch until processing

### 4.12 Splits

* Material removed for extraction requires:
  * New METRC package
  * Adjustment of source package
* Smalls removed for prerolls requires:
  * New METRC package
  * Adjustment of source package

### 4.13 Processing

* Smalls/Trim processed into hash/rosin
* New products tracked

## Section 5 — Traceability

All material must be traceable to:

* Harvest batch
* METRC package
* Tote records
* Processing records

## Section 6 — Control Points

| Step       | Control               |
| ---------- | --------------------- |
| Bucking    | Tote weights recorded |
| Packaging  | Batch = one package   |
| Processing | Input/output tracked  |
| Balance    | Real-time tracking    |
| Extraction | METRC split required  |

## Section 7 — Records

* Tote tracking records
* Trimmer reports
* Running balance report
* METRC records
