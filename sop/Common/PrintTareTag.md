# Print Tare Tag SOP

## 1. Purpose

To define the procedure for generating and applying tare tags to trim buckets.  A tare tag records the empty weight (tare) of a bucket so that net flower weight can be calculated accurately when the bucket is weighed on the scale.

---

## 2. Inputs

- Empty trim bucket
- Ranger or Scout scale connected and powered on
- Label printer powered on with labels loaded

---

## 3. Procedure — Ranger Scale (Recommended)

### 3.1 Launch the Application

1. From the main menu, navigate to Common → Print Tare Tag.
2. The Print Tare Tag window will open.

---

### 3.2 Select the Scale

1. Confirm **Ranger** is selected in the Scale radio buttons.
2. The status bar at the top of the screen will confirm "Scale: Ranger" when the scale is connected.

---

### 3.3 Zero the Scale

1. Make sure nothing is on the scale.
2. Click the **Tare Scale** button to zero the Ranger scale.
3. The weight display should read **0**.

---

### 3.4 Hang the Empty Bucket

1. Hang the empty bucket on the Ranger scale hook.
2. Wait for the weight reading to stabilize.
3. Confirm the weight is displayed in the **Weight (g)** field.

---

### 3.5 Print the Tare Tag

1. Click the **Print Tare Tag** button.
2. The label printer will print a tare tag showing the bucket's empty weight and a QR code encoding the tare value.

---

### 3.6 Apply the Tag

> **Important:** Apply the tare tag to the **bucket body — not the lid.**
> This prevents tare tags from being accidentally transferred from one bucket to another when lids are swapped.

1. Peel the tare tag from the label.
2. Affix it firmly to the side of the bucket.

---

## 4. Procedure — Scout Scale

The Scout scale does not support software tare commands.  Use the following procedure instead.

### 4.1 Select the Scale

1. In the Print Tare Tag window, select **Scout** in the Scale radio buttons.

---

### 4.2 Zero the Scale Manually

1. Make sure nothing is on the Scout scale platform.
2. Press the **Tare** button on the Scout scale itself to zero the display.
3. The weight display in the application should read **0**.

---

### 4.3 Weigh and Print

1. Place the empty bucket on the Scout scale platform.
2. Wait for the weight reading to stabilize.
3. Confirm the weight is displayed in the **Weight (g)** field.
4. Click **Print Tare Tag**.
5. Apply the printed tag to the **bucket body — not the lid**.

---

## 5. Notes

- Always tare the scale with nothing on it before hanging or placing a bucket.
- If the weight display does not update, check that the correct scale is selected and the scale is connected (visible in the status bar).
- Tare tags must stay with the same bucket throughout the harvest process.  Never move a tare tag from one bucket to another.
