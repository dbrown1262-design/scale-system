# Print Bucked Report SOP

## Purpose

This application generates a detailed report of all bucked flower totes weighed within a specified date range. The report is designed to facilitate accurate data entry into the METRC compliance system and includes signature lines for dual verification.

The primary purposes are to:
- Provide a complete record of bucked flower production for a date range
- Support accurate and efficient METRC data entry
- Enable quality control through dual verification
- Maintain compliance documentation

---

## Required Equipment

- Computer with application access
- PDF viewer or printer

---

## Operating the Application

### 1. Application Status

When the application opens, it displays:
- **Start Date:** First date of the date range to include
- **End Date:** Last date of the date range to include
- **Data grid:** Shows all bucked totes within the selected date range
- **Refresh Button:** Reloads data after changing dates
- **Print Report Button:** Generates and opens the PDF report

---

### 2. Select Date Range

To specify the date range for the report:

1. Click on the **Start Date** field.
2. Select the first date you want to include in the report.
3. Click on the **End Date** field.
4. Select the last date you want to include in the report.
5. Click **Refresh** to load the data.

**Date Entry:**
- Dates can be typed in YYYY-MM-DD format
- Both Start Date and End Date are inclusive- to get a report for one day, enter the same start and end date.

---

### 3. Review Data

The data grid displays the following columns for each bucked tote:
- **Crop No:** The crop number (e.g., "250101")
- **Strain:** The cannabis strain name
- **Tote No:** The internal number assigned to the tote
- **Weight:** The weight in grams
- **Buck Date:** The date the tote was weighed
- **Harvest Date:** The date the strain was harvested

**Sorting:**
- Click any column header to sort by that column

---

### 4. Generate Report

To print the report:

1. Verify the correct date range is selected.
2. Click **Refresh** to ensure data is current.
3. Click **Print Report**.
4. The system generates a PDF report and opens it automatically.
5. Review the PDF for accuracy.
6. Print the report or save it as needed.

---

### 5. Report Contents

The PDF report includes:

**Header Section:**
- Report title: "Bucked Totes Report"
- Date range covered

**Data Table:**
- Crop Number
- Strain Name
- Tote Number
- Weight (in grams)
- Buck Date
- Harvest Date

**Footer Section:**
- Total number of totes

**Signature Lines:**
- "Checked By" — Person verifying the data entry

---

### 6. Troubleshooting

**No data appears:**
- Verify the date range includes days when bucked totes were weighed
- Check that Start Date is before or equal to End Date
- Click **Refresh** after adjusting dates
- Confirm bucked totes were actually weighed during this period

**Missing totes:**
- Verify the date range includes all needed dates
- Expand the date range if needed
- Check that totes were saved properly in Weigh Bucked application
- Contact supervisor if totes appear to be missing from database

**Wrong dates showing:**
- Clear the date fields and re-enter
- Use MM/DD/YYYY format
- Verify year is correct (easy to miss)
- Click **Refresh** after correcting dates

**PDF won't open:**
- Ensure a PDF viewer is installed
- Check that file was generated (look for success message)
- Try manually opening from file location if auto-open fails
- Verify sufficient disk space for PDF generation

**Totals don't match expectations:**
- Verify correct date range is selected
- Check if any totes were weighed outside the date range
- Confirm all crops/strains are represented
- Review individual weights for obvious errors
- Re-weigh any totes with questionable weights

**Print quality issues:**
- Adjust printer settings for better quality
- Use landscape orientation if table is cut off
- Consider saving as PDF and printing from PDF viewer
- Check printer has adequate toner/ink

---

### 7. Report Retention

- File signed reports in chronological order
- Maintain reports for the duration required by state regulations
- Keep reports accessible for audits
- Consider digital backup copies
- Retain both the printed signed copy and digital PDF
